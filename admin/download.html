Fitur Utama

Presensi GPS & Foto Selfie

Validasi titik koordinat lokasi kantor toko dan kamera langsung saat absen masuk maupun pulang kerja.

Pengaturan Shift Fleksibel

Mendukung pembagian shift kerja (CS, Content Creator, Host Live Streaming) dengan toleransi keterlambatan.

Pelacakan Tugas Harian

Karyawan dapat melihat dan memperbarui status daftar tugas langsung dari antarmuka aplikasi.

ID Card Digital Staf

Kartu identitas karyawan digital dengan nomor identitas dan tombol salin nomor ID sekali klik.

Buka Aplikasi & Masuk

Tanya Jawab

Bagaimana jika saya tidak ingin mengunduh file APK?

Anda dapat membuka website ini melalui browser Chrome di Android, lalu pilih menu "Tambahkan ke Layar Utama" (PWA). Aplikasi akan langsung terpasang tanpa file APK.

Bagaimana cara mendapatkan akun login?

Akun didaftarkan oleh Administrator toko melalui Panel Admin (menu Karyawan ➜ Tambah Karyawan).

Mengapa aplikasi membutuhkan izin kamera dan lokasi?

Izin kamera digunakan untuk selfie saat absen, dan izin lokasi digunakan untuk memastikan presensi dilakukan di area kantor.
