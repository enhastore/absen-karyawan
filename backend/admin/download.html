Pertanyaan Sering Diajukan (FAQ)

Jawaban atas pertanyaan umum seputar instalasi dan penggunaan AbsenKu.

Bagaimana jika saya ingin memakai tanpa download APK?
Anda bisa langsung membuka link website di Google Chrome HP Android Anda, lalu tekan titik tiga di pojok kanan atas dan pilih "Instal Aplikasi" atau "Tambahkan ke Layar Utama". Aplikasi langsung terpasang di HP Anda tanpa unduh file APK!
Bagaimana cara karyawan mendapatkan akun login?
Akun dibuat langsung oleh Administrator toko melalui Panel Admin (menu Karyawan ➜ Tambah Karyawan). Setelah Admin menginput nama, email, dan sandi, staf bisa langsung login detik itu juga.
Mengapa aplikasi meminta izin Lokasi (GPS) dan Kamera?
Izin lokasi dibutuhkan untuk memvalidasi bahwa Anda berada di area kantor atau titik kerja yang sah. Izin kamera digunakan untuk verifikasi foto selfie saat melakukan absen masuk dan pulang.
Apakah aplikasi ini gratis?
Ya, 100% gratis selamanya. Backend dan database berjalan di infrastruktur cloud Vercel & Supabase tanpa biaya langganan bulanan.
